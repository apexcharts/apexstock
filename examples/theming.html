ApexStock • Theming

Three ways to change how a chart looks, on one chart. A mode is the baseline. A preset is a named appearance that retints both the plot and the chrome. CSS token overrides restyle the chrome from your own stylesheet, with no fork, and layer on top of whichever of the two is active.

Mode updateTheme(mode), which also clears any preset
Preset
setThemePreset(name) or theme: { preset }. "vaporwave" is not built in: it is registered by this page with ApexStock.registerTheme().
CSS skin Re-declares --apexstock-* tokens in the page stylesheet. Chrome only: the plot is drawn from JS, so a preset still owns the candles and grid underneath.
